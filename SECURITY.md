# Security Policy

## Supported versions

Security fixes are applied to the latest `main` branch and the latest tagged
release.

## Reporting a vulnerability

Please do not report credentials, private input data, or an exploitable bug in
a public issue. Use GitHub's private vulnerability reporting or a GitHub
Security Advisory for this repository. If that option is unavailable, contact
the repository maintainer through the GitHub profile before public disclosure.

Include the affected commit or release, reproduction steps, impact, and any
known mitigation. Remove credentials from all reports. If a credential has
entered Git history, revoke or rotate it immediately; deleting the file alone
does not remove it from public history.
